# Симулятор Додепа 🎰

Ироничный браузерный симулятор лудомана: 28 дней жизни, зарплата, счета, долги и один очень честный слот.
Игра **высмеивает азартные игры, а не продвигает их**: казино здесь всегда в плюсе, а единственная победа — вовремя уйти.
Цель проекта — релиз в Steam (сейчас это веб-сборка на Vue 3).

> ⚠️ **Дисклеймер.** Реальных денег в игре нет: нельзя ни пополнить, ни вывести, ни купить что-либо. Нет платёжных
> кнопок, сетевых запросов и наград за ежедневный вход. Все названия казино, стримеров и сервисов вымышлены.
> Если азартные игры стали проблемой, обратитесь за помощью: [Анонимные Игроки — группы поддержки](https://www.gamblersanonymous.org/).

## Концепция

- **Сатира на лудоманию.** Каждый приём онлайн-казино (бонус 200% «по умолчанию», тикер чужих выигрышей, фейковый
  таймер «бонус сгорит», «почти-выигрыш», два подтверждения на выход и ни одного на депозит) показан как есть и
  тут же разобран.
- **Витрина и Изнанка.** Витрина — неоновый сайт казино. Изнанка (👓 «Снять очки», клавиша `I`) — та же игра на
  бумаге: фактический RTP, проигрыши, замаскированные под выигрыш (LDW), прогноз отыгрыша бонуса, проценты по долгу,
  время, которое «пролетело незаметно». У каждого казино-элемента есть честный двойник.
- **Нет стратегии.** Слот честно случаен, RTP 90%. Балансный симулятор (`tools/balance-sim/sim.mjs`) подтверждает:
  любая стратегия с регулярным казино проигрывает честной работе.

## Ран: 28 дней

- День: **утро** (приход выводов, карточка события) → **день** (100⚡ на действия и спины) → **сон** (−300₽ на жизнь,
  проценты, спад тильта, случайное событие ночи).
- **Счета** на 7, 14, 21 и 28 день платятся только из кошелька. Одна отсрочка на ран (+50%); второй неоплаченный
  счёт — коллекторы.
- **Развилка на 28-й день:** «ЗАВЯЗАТЬ» (только без долга; если на сайте остались деньги — предупреждение, что вывод
  придёт «завтра», которого не будет) или «ЕЩЁ НЕДЕЛЮ» (счета растут ×1.35).
- **7 концовок:** «Завязал» (оценка A/B/C), «Коллекторы», «Сел», «Семья ушла», «Ночь в казино ×3», «Минимализм» и
  секретная. После концовки — **Выписка**: сколько проиграно, фактический RTP, проценты, штрафы, потерянные вещи и
  «эквиваленты» (шаурмы, подарки маме).

## Механики

- **Кошелёк ≠ баланс казино.** Депозит мгновенный, вывод — утром и с комиссией 5%. Бонус 200% запирает баланс
  вейджером ×40 (отыгрывают ~8%).
- **Слот** 3×3 с таблицей выплат, near-miss и LDW; ставки ½ / ×2 / MIN / «ДОДЕП ВСЁ». Исход считается в ядре и
  сохраняется до анимации (F5 не отменяет спин).
- **Жизнь:** смены (с повышениями), темки (риск штрафа и тюрьмы), помощь семье, займы у друзей (❤️ репутация),
  банк и МФО (сложные проценты), ломбард (выкуп за 130%).
- **Тильт 🔥:** растёт от проигрышей; на 40 и 70 меняется интерфейс, на 100 — «ночь в казино» (−20% баланса).
- **29 карточек событий сна** (мама, Серёга, коллектор Эдуард, менеджер Анжелика, бытовые неприятности).

## Ачивки и косметика

- **31 достижение** (часть скрытых) и коллекция из 7 концовок. Каждая ачивка имеет честный подзаголовок.
- Награды — **только косметика**: скины символов слота, темы оформления, звук-паки (включая «Честный», где все исходы
  звучат одинаково) и титулы. Мета-валюты и бонусов между ранами нет.
- **Гардероб**, **Достижения**, **Концовки** и статистика «за всё время» — в главном меню.

## Управление

| Клавиша | Действие |
|---|---|
| `Пробел` | Спин (фокус в слоте или ни на чём) |
| `−` / `=` | Ставка ½ / ×2 |
| `0` | Минимальная ставка |
| `D` | Касса |
| `I` | 👓 Витрина ↔ Изнанка |
| `L` / `C` | К Жизни / к Казино |
| `N` | Лечь спать |
| `←` `→` / `1` `2` | Вариант A / B в карточке и на развилке |
| `M` | Звук вкл/выкл |
| `?` / `F1` | Как играть |
| `F6` | Регионы: шапка → казино → жизнь → хроника |
| `Esc` | Закрыть слой / пауза |

На телефоне — вкладки «🎰 Казино / 📋 Жизнь / 👓 Изнанка» и липкая кнопка действия внизу.

## Структура проекта

```
src/
├─ game/          # Чистое ядро: команды, ночь/утро, слот, правила, концовки, статистика, ачивки,
│  │              # Выписка и Изнанка (view.ts). Без Vue/DOM/Math.random — детерминировано по сиду
│  ├─ commands/   # Обработчики команд (casino, slot, work, bank, pawn, friends, day)
│  ├─ config/     # Баланс economy-v1, таблица слота, ачивки, косметика — единственный источник чисел
│  ├─ content/    # Карточки событий сна
│  └─ save/       # Схема сейва, миграции (legacy → v3), валидация
├─ stores/        # Pinia: game.ts — тонкая обёртка над ядром (execute/spin/сейв), ui.ts — показ спина
├─ components/
│  ├─ game/       # Оболочка рана: шапка-сайт, слот, «Жизнь», касса, хроника, Протокол Изнанки, модалки
│  ├─ phases/     # Утро, карточка события, счета, итог дня, развилка, концовка, Выписка
│  ├─ menu/       # Главное меню
│  ├─ meta/       # Гардероб, достижения, коллекция концовок
│  ├─ overlays/   # Пауза, настройки, «Как играть», тосты
│  └─ ui/         # Дизайн-система: кнопки, модалки, тикер, баннеры, штампы, рамка слота
├─ composables/   # Навигация оболочки, тема/слой, звук, тосты, учёт времени
├─ audio/         # Процедурные SFX на Web Audio, звук-паки, режиссёр событий
├─ i18n/          # ru.ts — тексты ядра (хроника, отказы, концовки, карточки); ui.ts — строки интерфейса
├─ platform/      # Всё, что зависит от окружения: хранилище (сейчас localStorage), ачивки платформы, сиды
├─ skins/         # Отображение символов слота по скинам
└─ styles/        # Токены и темы, базовые стили, шрифты, VFX
tools/
├─ balance-sim/   # Монте-Карло симулятор экономики (node tools/balance-sim/sim.mjs --runs 2000)
└─ a11y/          # Скрипты аудита доступности и контраста
```

## Команды

```sh
npm install          # зависимости (Node ^20.19 или >= 22.12)
npm run dev          # dev-сервер с hot-reload: http://localhost:5173/simulator-dodepa/
npm test             # vitest (ядро, сейвы, стор, тексты, аудио)
npm run coverage     # vitest с покрытием
npm run type-check   # vue-tsc
npm run build-only   # прод-сборка vite в dist/
npm run build        # type-check + build-only параллельно
npm run preview      # локальный просмотр сборки
```

## Документы

- `design/` — creative vision, исследование рынка, GDD структуры рана (`gdd-run-structure.md`), экономика и
  симуляция (`economy-v1.md`), системная спека (тильт, честная статистика, ачивки, косметика), контент-пак (все
  тексты), UX-флоу, art bible, спека звука (`audio/`).
- `production/` — архитектура и ADR (`architecture.md`), технический аудит, планы задач (`tasks-creative.md`,
  `tasks-technical.md`), отчёты QA (`qa/acceptance-report.md`, `qa/accessibility-report.md`) и состояние сессии.
