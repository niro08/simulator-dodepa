## 0. Суть в пяти правилах

1. **Витрина кричит, Изнанка шепчет, Выписка молчит.** Громкость визуала падает вместе с честностью: неон → серая бумага → белый лист.
2. **Неон не несёт смысл.** Неон идёт только на обводки, свечения, крупные цифры (≥ 28px) и декор. Смысловой текст всегда светлый на тёмном или тёмный на светлом, контраст ≥ 4.5:1.
3. **Каждый «кричащий» элемент имеет бумажного двойника** (пиллар 1). Нет честной подписи — элемент не выходит.
4. **Жизнь всегда бумажная.** Даже внутри Витрины панель «Жизнь» — это квитанция, а не неон. Казино и быт не смешиваются по материалу.
5. **Пародия, а не копия.** Узнаваемо, как жанр «сайт онлайн-казино», но без реальных брендов, логотипов, цветовых пар конкретных операторов, стримеров и платёжных систем.

## 1. Два визуальных слоя

### 1.1 «Витрина» — неоновое казино

| Аспект | Правило |
|---|---|
| Материал | Тёмный фиолетовый «космос» (`--bg-void`), стеклянные панели, золотая фаска, неоновые трубки-обводки |
| Свет | Всё светится изнутри: `box-shadow`/`text-shadow` в 2–3 слоя. Источник света — сами элементы, теней «от солнца» нет |
| Фон страницы | `radial-gradient` пятна магенты и циана по углам + мелкая сетка «звёздной пыли» (SVG-паттерн 2%) |
| Форма | Скошенные баннеры `skewX(-6deg)`, пилюли, ленты-ribbon, звёзды-бёрсты. Радиусы средние (12–20px) |
| Текст | КАПС в дисплее, восклицания, эмодзи ≤ 2 на строку, звёздочки-сноски `*` у каждого обещания |
| Числа | Огромные, золотые, с тиснением, `tabular-nums`, анимированный count-up |
| Движение | Постоянное, но медленное: пульс CTA 1.2 с, бегущие лампочки, тикер, вращение лучей 30 с |
| Звук (для CD-20) | Праздничный на любом «выигрыше», включая LDW |

### 1.2 «Изнанка» — серая честная правда

| Аспект | Правило |
|---|---|
| Материал | Бумага `--paper #E9E5DA`, линовка как в бланке, перфорация сверху, скрепки/штампы. Референс — квитанция ЖКХ + банковская выписка + протокол |
| Свет | Плоский. Одна тень бумаги `0 1px 2px` — лист лежит на столе |
| Форма | Прямые углы (радиус 2px), таблицы с точечными выносками `…………`, рамки 1px `--ink` |
| Текст | `--font-mono`, строчные, канцелярит: «Операция №1432. Ставка 100₽. Возврат 50₽. Итог −50₽». Рукописные пометки `--font-hand` синей ручкой — только для «Жизни» (мама, Серёга) |
| Числа | Того же размера, что и текст. Минус всегда виден, итог подчёркнут двойной линией |
| Акценты | Только штампы: красный `ПРОИГРЫШ`/`ПРИЁМ`/`−EV`, синий `ПРОВЕДЕНО`, зелёный `ОПЛАЧЕНО`. Жёлтый маркер `--highlighter` выделяет главную цифру |
| Движение | Почти нет: «шлёп» штампа (180 мс, один раз), печать строк выписки по одной (60 мс/строка) |
| Звук | Пак «Честный»: сухой щелчок, выигрыш и проигрыш звучат одинаково |

### 1.3 Переключение «👓 Снять очки»

**Где кнопка.** Шапка справа, всегда видна (десктоп). На мобильном — вкладка «Изнанка» в нижнем таб-баре и кнопка 👓 в шапке. Хоткей `G` (glasses). Горячая клавиша подписана в тултипе.

**Состояния кнопки:**
- в Витрине: `👓 Снять очки` — вторичная кнопка с циановой обводкой, без пульса (не конкурирует с CTA);
- в Изнанке: `🕶️ Надеть обратно` — бумажная кнопка с чернильной рамкой.

**Механика (для CD-17):**

```
<html data-theme="neon" data-layer="vitrina|iznanka" class="calm?">
  <div class="vitrina">  ← вся казино-поверхность (шапка, баннеры, тикеры, лобби, слот)
     … элементы с .honest-тегами внутри …
  </div>
  <aside class="life paper">  ← «Жизнь» (бумага всегда, фильтр НЕ применяется)
  <Teleport to="body"> модалки, тосты, мобильный таб-бар, fixed CTA
```

1. `html[data-layer="iznanka"] .vitrina { filter: grayscale(1) contrast(.9) brightness(.92); }`.
   - Фильтр гасит цвет **эмодзи** — токенами этого не сделать.
   - `filter` создаёт containing block для `position: fixed`, поэтому все fixed-элементы (модалки, тосты, нижний CTA, таб-бар) выносятся из `.vitrina` через `<Teleport>`.
   - Сам фильтр **не анимируем**: он дорогой в анимации.
2. Токены свечений обнуляются (`--glow-*: none`), все анимации внутри `.vitrina` получают `animation-play-state: paused`, тикеры замирают.
3. Появляются честные ярлыки `.honest` (в Витрине они `display:none`). Появление — только `opacity` за 80 мс, без движения. Бюджет переключения ≤ 100 мс (CD-17).
4. Поверх выигрышей и баннеров ставятся штампы (см. §3.14).
5. Звук переключается на пак «Честный» на время Изнанки.
6. Обратное переключение симметрично. Состояние слоя сохраняется в `dodepaMeta` и считает время для ачивки #23 «Прозрение».

**Что именно меняется на экране:**

### 2.5 Радиусы, тени, свечения, спейсинг, слои

- **Спейсинг** — шаг 4px: `4 · 8 · 12 · 16 · 24 · 32 · 48 · 64`. Внутренние отступы панели: 16 (моб) / 24 (деск). Гаттер сетки: 16 / 24. Боковые поля страницы на мобильном 12–16px.
- **Радиусы.** Витрина: `xs 4` (бейдж), `sm 8` (инпут), `md 12` (карточка, кнопка), `lg 20` (рамка слота, модалка), `pill 999`. Изнанка: `2px` везде.
- **Тени.** Витрина: подъём `0 8px 24px rgba(0,0,0,.45)`. Бумага: `0 1px 0 rgba(255,255,255,.6) inset, 0 1px 2px rgba(0,0,0,.18)`.
- **Свечения.** Три слоя: ядро 4px, ореол 12px (60%), туман 28px (35%). Дорогие, поэтому постоянное свечение не больше чем у ~12 элементов на экране одновременно. Анимируем `opacity` псевдоэлемента со свечением, а не сам `box-shadow`.
- **z-index:** фон 0 · контент 1 · липкая шапка 50 · таб-бар/fixed CTA 60 · тосты 80 · модалка 100 · VFX-частицы 110 · вспышка 777 120.

## 4. Девять скинов слота

Скин — это данные (CD-19): `{ id, symbols[8], frameClass, glow, accent, bg, fx }`. Порядок символов **фиксирован по тирам выплат**, чтобы данные скинов и таблица исходов не путались:

`[0] 0.5x (LDW) · [1] 1x · [2] 2x · [3] 5x · [4] 10x · [5] 25x · [6] 777/100x · [7] пустышка`

Смена скина меняет только внешний вид: исходы от набора символов не зависят (тест CD-19).

### 5.1 Фотобезопасность (обязательно для CD-18 и QA)

1. **Никаких вспышек чаще 3 Гц.** Рабочий потолок игры — **2 Гц** для любого мигания (лампы, LIVE-точка, вывески). Вспышка — это перепад яркости ≥ 10% туда и обратно.
2. **Полноэкранных вспышек нет вообще.** Единственная вспышка (джекпот) — одна, внутри корпуса слота (< 25% вьюпорта при 1280×720), не повторяется чаще раза в 2 с.
3. **Красные насыщенные вспышки запрещены** (самый опасный тип). Тильт-виньетка пульсирует 0.5 Гц с малой амплитудой и не мигает.
4. **Лампа «выкл» не чёрная** (`--lamp-off #5A4A2A`) — это снижает перепад яркости при беге.
5. Никаких полосатых мигающих паттернов (жалюзи и сканлайны статичны или медленно дрейфуют, без мерцания контраста).
6. Параллакса и зума по скроллу нет.
7. **Два выключателя:** системный `prefers-reduced-motion: reduce` и настройка «Меньше мигания» (`html.calm`, хранится в `dodepaMeta`, по умолчанию выключена, при первом запуске предлагается в меню). Оба гасят: пульсы, бег ламп, тикеры, карусель, шейк, вспышку, частицы, блики, дождь. Смысл (суммы, штампы, результат) остаётся.
8. Производительность: только `transform`/`opacity` в циклах. `box-shadow`, `filter`, `width` не анимируем. Одновременно ≤ 2 бесконечных анимации свечения на крупных элементах. 60 fps, без long tasks > 50 мс во время спина (CD-18).

## 7. Do / Don't

| ✅ Делаем | ⛔ Не делаем |
|---|---|
| Обобщённая пародия жанра: неон, золото, «зеркало», звёздочки | Реальные бренды, логотипы, фирменные цветовые пары операторов, стримеров, платёжек, криптобирж |
| Эмодзи, CSS, инлайн-SVG, Google Fonts (OFL) | Фотографии, растровые картинки, внешние ассеты, гифки |
| Неон на обводках, свечениях, крупных цифрах ≥ 28px | Мелкий смысловой текст неоном; белый текст на оранжевом/магенте |
| Каждый «крик» имеет честный ярлык | Элемент Витрины без двойника |
| LDW празднуется как 2x (сатира) | Разные эффекты для LDW и реального выигрыша в Витрине |
| Потери скрыты в Витрине и **очевидны** в Изнанке | Скрывать потери и в Изнанке |
| Мигание ≤ 2 Гц, спокойный режим | Полноэкранные вспышки, красные стробы, мигающие полосы |
| Сноски ≥ 11px, контраст ≥ 4.5 | «6px, чтобы смешно» — шутку делаем цветом и местом, не нечитаемостью |
| Слот красивый, но «пустой» по решениям | Визуальные подсказки «скоро выпадет», индикаторы «горячего» автомата с намёком на предсказание |
| 🧯 вместо 🚬, без гламура алкоголя в Витрине | Романтизация курения, алкоголя, долга |

## 9. Спецификация ассетов и нейминг

- Внешних файлов нет. Инлайн-SVG — Vue-компоненты `src/components/art/Svg*.vue` или строки в `src/game/content/art.ts` (решение ui-programmer). Максимум 4 КБ на SVG, `viewBox` обязателен, цвета через `currentColor` / CSS-переменные.
- Нейминг (из роли AD, для CSS-классов и SVG): `ui_btn_cta`, `ui_badge_hot`, `ui_logo_dodep`, `vfx_coinburst`, `vfx_jackpot_flash`, `skin_bandit90_frame`, `theme_monday`. CSS-классы в kebab-case с тем же смыслом: `.btn-cta`, `.badge-hot`, `.skin-bandit90`.
- Эмодзи рендерятся системным шрифтом, поэтому вид на разных ОС разный. Для слота задаём `font-family: 'Apple Color Emoji', 'Segoe UI Emoji', 'Noto Color Emoji', sans-serif`. QA проверяет Windows 10/11, macOS, Android.
- Кириллические сокращения сумм: `12,5 тыс ₽` на мобильном при ширине пилюли < 96px.
