## 0. Как читать

- Вайрфреймы — это **схема** иерархии и расположения. Пиксели, цвета и шрифты задаёт арт-библия.
- Эмодзи в моноширинном тексте занимают 2 колонки, поэтому правые края рамок местами «съезжают». Это нормально.
- Обозначения:
  - `[Кнопка]` — кнопка;
  - `[▶КНОПКА◀]` — «кричащая» CTA Витрины (пульс, градиент);
  - `( 3 450₽ )` — пилюля баланса;
  - `▓▓░░` — прогресс-бар;
  - `≋ … ≋` — тикер;
  - `*` — сноска;
  - `⟨Пробел⟩` — подсказка горячей клавиши на кнопке;
  - `→ S07` — переход на экран с этим ID.
- **Два голоса интерфейса:**
  - **Витрина** — кислотный казино-сайт: КАПС, неон, звёздочки;
  - **Бумага** — панель «Жизнь», Изнанка, Выписка, меню, настройки: серая бумага, моношрифт, сухой тон.

  Правило: **всё, что системное и мета** (меню, настройки, пауза, коллекция), говорит голосом Бумаги и **не использует тёмных паттернов**. Пародия живёт только внутри игрового мира (§9).

## 2. Принципы, которые не нарушаем (сводка)

Подробности и проверки — в §10. Здесь коротко, чтобы держать в голове при чтении макетов.

1. **Выйти можно всегда.** `Esc` или `⏸` открывает паузу, оттуда один пункт ведёт в меню. Это максимум 2 действия. Сейв автоматический, поэтому подтверждения не нужны. Внутриигровое трение (тильт ≥70) никогда не касается системного выхода.
2. **Цена видна до нажатия, итог — после.** На каждой кнопке действия написаны ⚡, ₽, ❤️, 🔥 и шанс. После действия в Хронике есть строка с итогом со знаком.
3. **Изнанка в одном действии** с любого экрана рана (👓, `I`, мобильная вкладка).
4. **Звук и мигание под контролем.** 🔊 и `M` работают всегда. «Меньше мигания» включается по умолчанию при `prefers-reduced-motion`. Мигание не чаще 3 Гц.
5. **Недоступное объясняет себя.** Кнопка получает `aria-disabled`, остаётся в фокусе, а под ней написана причина. Молча недоступных кнопок нет.
6. **Мета чистая.** Нет daily-наград, стриков, таймеров и пушей. «Продолжить» не мигает.

## 5. Горячие клавиши и ввод

Клавиши привязаны к `KeyboardEvent.code`, поэтому работают при русской раскладке (`KeyI` = «Ш»). В подсказках на кнопках показываем латинскую букву. Список открывается по `?` (S07) и есть в Настройках. Ремаппинг — P1 (Steam).

| Клавиша | Действие | Где работает | Примечание |
|---|---|---|---|
| `Пробел` | Спин | S10, если фокус в зоне слота или ни на чём | Если фокус на другой кнопке, Пробел нажимает её (нативно). Иначе будет путаница: «нажал Пробел на "Взять МФО" — а оно крутит» |
| `Enter` | Спин из поля ставки; активировать кнопку в фокусе | поле ставки, везде | |
| `-` / `=` | Ставка ½ / ×2 | S11 | |
| `0` | Ставка MIN | S11 | |
| — | **ДОДЕП ВСЁ** | — | **Намеренно без клавиши.** Кнопка только выставляет ставку, крутить надо отдельно (защита от случайного all-in) |
| `D` | Открыть Кассу | S10 | |
| `I` | 👓 Витрина ↔ Изнанка | S10, S12, S43, S51 | |
| `L` / `C` | Фокус на панель Жизнь / Казино (моб.: вкладка) | S10 | |
| `N` | Лечь спать (открывает S40) | S10 | |
| `←` / `→` или `1` / `2` | Вариант A / B | S42, S46 | В S46 без авто-выбора: нужен `Enter` для подтверждения |
| `Esc` | Закрыть слой / Пауза | везде | §3.4 |
| `M` | Звук вкл/выкл (всё сразу) | везде | Тост «Звук выключен» |
| `?` / `F1` | Памятка и клавиши | везде | |
| `F6` | Цикл по регионам: Шапка → Казино → Жизнь → Хроника | S10 | Для клавиатуры и скринридера |
| `Tab` / `Shift+Tab` | Порядок фокуса (у каждого экрана свой, см. ниже) | везде | Фокус всегда видим (кольцо 2 px, контраст ≥ 3:1) |

**Когда клавиши не срабатывают:**

- во время анимации спина (вводы не буферизуем, кроме `Esc`, `M`, `I`);
- при открытом диалоге (работают только клавиши диалога);
- в текстовом поле (кроме `Enter` и `Esc`).

**Тач.**

- Цели ≥ 44×44 px.
- «КРУТИТЬ» — в нижней трети экрана, в зоне большого пальца (закон Фиттса).
- Свайпы только дублируют кнопки (событие: свайп влево/вправо). Навигация свайпом не делается, чтобы не было случайных переходов.

- `A` — активировать / спин;
- `B` — назад / Esc;
- `Y` — 👓;
- `X` — Касса;

### S10 · Игровой экран — Витрина (+ S11 Слот, S20 Жизнь)

**Иерархия Витрины (намеренно «казиношная», это пародия):**

1. баланс казино и «ДЕПОЗИТ»;
2. хиро-бонус;
3. слот и «КРУТИТЬ»;
4. тикер побед;
5. кошелёк мелко.

**Иерархия Жизни (честная, всегда видна рядом):**

1. день и до счёта N дней / сумма / хватает ли;
2. ⚡;
3. 🔥 и ❤️;
4. долг и проценты;
5. вещи;
6. действия;
7. «Спать».

> **Главный UX-приём экрана.** Витрина и Жизнь конкурируют за внимание. Витрина кричит, Жизнь говорит тихо, но её цифры **никогда не скрыты и не уменьшены ниже нормы**. Игрок сам выбирает, куда смотреть. Это и есть игра.

| Состояние | Что видит игрок |
|---|---|
| loading (спин) | Контролы слота `aria-disabled`, Жизнь доступна только для чтения, «КРУТИТЬ» → «…» |
| empty: баланс казино 0 | Кнопка «КРУТИТЬ» заменяется на «[▶ДЕПОЗИТ◀] чтобы играть» (открывает S12). В Изнанке подпись: «Кнопка спина превратилась в депозит. Это приём» |
| empty: хроника | «Здесь будет видно, куда ушли деньги.» |
| disabled: ⚡ < 2 | «КРУТИТЬ» `aria-disabled`, причина: «Нет сил. Даже на это. Ложись спать». При 🔥≥70 спин стоит 0⚡, и эта блокировка не срабатывает — это механика, а не баг: в Изнанке «Спины при тильте ≥70 не тратят ⚡. Ты не замечаешь времени» |
| disabled: ставка > баланса казино | Ошибка под полем: «Ставка больше баланса казино (3 450₽)» + [Поставить 3 450₽] |
| error: ставка < 50 / не число | На blur зажимается до 50 и шага 50, строка «Минимум 50₽» |
| 🔥 ≥ 40 | Баннер «ОТЫГРАЙСЯ!» заменяет хиро. UI Витрины насыщеннее. **Шапка, 🔊, ⏸, 👓 не меняются** |
| 🔥 ≥ 70 | Переход в Жизнь проходит через S14. Спин за 0⚡. Статус-строка 🔥 красная + текст «ТИЛЬТ» (не только цвет) |
| бонус активен | Баланс казино помечен 🔒, прогресс отыгрыша в слоте, вывод в S12 заблокирован с причиной |
| вывод в пути | В шапке у кошелька: «+950₽ утром ⏳» |

### S11 · Слот (детально)

```
┌─ ЗОЛОТО ДОДЕПА ─────────────────────── ◦•◦•◦•◦•◦•◦ ─┐
│   [скин: Фруктовый]                   быстрый спин ☐ │  ← быстрый спин дублирует Настройки
│              ┌────────┬────────┬────────┐            │
│              │   🍒   │   7️⃣   │   7️⃣   │            │  ← near-miss: 2 семёрки + 3-я
│              └────────┴────────┴────────┘            │    «проскальзывает» мимо линии
│   РЕЗУЛЬТАТ (aria-live=polite):                      │
│      ✨ ВЫИГРЫШ! +50₽ ✨     (LDW празднуется как 2x) │
│   Ставка [   100 ]₽   [½] [×2] [MIN]                 │
│                                    [ДОДЕП ВСЁ 3 450₽]│  ← отодвинута от КРУТИТЬ, ≥ 24 px зазор
│   ┌────────────────────────────────────────────────┐ │
│   │         🎰 К Р У Т И Т Ь  · 2⚡   ⟨Пробел⟩       │ │
│   └────────────────────────────────────────────────┘ │
│   Бонус: отыграно 1 240 из 60 000₽ ▓░░░░░░░ 2%*      │
└──────────────────────────────────────────────────────┘
```

- **Длительность:** 1.2 с (быстрый — 0.4 с). Результат появляется после остановки 3-го барабана. Тост ачивки ждёт конца анимации.
- **Скринридер:** в Витрине объявление идёт так: «Выигрыш 50 рублей. Ставка 100. Итог минус 50». Честный итог **всегда** добавляется в конце. Незрячий игрок не может «посмотреть на Изнанку краем глаза», поэтому он не должен быть обманут сильнее зрячего.
- **ДОДЕП ВСЁ** только выставляет ставку = весь баланс казино и подсвечивает поле. Спин — отдельным нажатием.
- **Выход из казино** — отдельной кнопки на десктопе нет, Жизнь видна рядом. «Уйти» = любое действие в Жизни или «Спать». При 🔥≥70 оно проходит через S14 (§6.3). На мобильном «уйти» = тап по вкладке «Жизнь».

- Витрина уходит в `grayscale`;

### S13 · Бонус 200%: оффер и правила

Показывается как **отдельный диалог только один раз** — при первом нажатии «ЗАБРАТЬ БОНУС» в хиро. Во всех остальных случаях достаточно галочки в S12.

```
┌──────────────────────────────────────────────────┐
│ ★★★ БОНУС 200% НА ПЕРВЫЙ ДЕП! ★★★                │
│ Депни 1 000₽ — получи 3 000₽ НА ИГРУ!*           │
│ ⏱ Предложение сгорит через 04:59                 │
│                                                  │
│ [▶ ЗАБРАТЬ ◀]        [ Без бонуса ]               │  ← обе кнопки реально работают
│ ──────────────────────────────────────────────── │
│ *Условия (читаемым шрифтом, не свёрнуто):        │
│ • бонус = 2× депозита, максимум 10 000₽          │
│ • весь баланс казино заблокирован, пока не       │
│   поставишь 30× бонуса (напр. 60 000₽)           │
│ • до этого вывод невозможен                      │
│ • таймер декоративный                            │

```

- **Фокус по умолчанию:** «Без бонуса». Витрина кричит «ЗАБРАТЬ», но клавиатура не толкает игрока в ловушку.
- **Мобильный:** тот же текст на полноэкранной шторке, кнопки внизу, условия прокручиваются над ними.

### S14 · Выход из казино при 🔥 ≥ 70 (двойное подтверждение, пародия)

Срабатывает, когда игрок при 🔥≥70 нажимает действие в Жизни или «Спать». На мобильном — при тапе по вкладке «Жизнь». **Не срабатывает** на ⏸ / Esc → Пауза → Меню, на 👓 и на вкладке «Изнанка».

```
ШАГ 1                                        ШАГ 2
┌───────────────────────────────────────┐    ┌───────────────────────────────────────┐
│ УЖЕ УХОДИШЬ?! 😱                       │    │ ТОЧНО?! Следующий спин может быть     │

│                                       │    │                                       │
```

- «Остаться» ничего не крутит само, только закрывает диалог.

## 8. Обучение: первые 2 дня (вместо HowToPlay)

**Правила подсказок:**

- голос Бумаги, 1–2 строки;
- максимум **1 подсказка одновременно**;
- подсказка не блокирует экран: коуч-марка со стрелкой и кнопками [Понятно] и [Скрыть все];
- включается заново в S06.

## 9. Тёмные паттерны казино, которые мы пародируем

**Правило пародии.** Каждый приём:

1. живёт **только в игровом мире** (Витрина, внутриигровые диалоги);
2. имеет **честного двойника** на расстоянии ≤ 1 действия (👓, сноска нормального размера, строка «Изнанка: …», чек, Выписка);
3. **не обманывает о правилах** — правила всегда доступны простым текстом;
4. **не касается системного UX**: меню, пауза, настройки, выход, звук, фотобезопасность;
5. не ломает доступность: мигание ≤ 3 Гц, контраст, клавиатура.

Приём, который нельзя разоблачить на экране, не выпускаем (пиллар 1).

| # | Приём (термин) | Как в реальных казино | Как показываем в Витрине | Как разоблачаем | Граница (чего не делаем) |
|---|---|---|---|---|---|
| 1 | **Бонус с вейджером** | «200% на деп» с отыгрышем ×30–×50 мелким шрифтом | Хиро + галочка в Кассе + S13 «ЗАБРАТЬ» | Условия в S13 полным шрифтом. Прогресс отыгрыша в слоте. Изнанка: «ожидаемый остаток ≈ 0₽», «отыгрывают ~1 из 9» | Не прячем условия за «Подробнее», если бонус принимается впервые |

**Что мы НЕ пародируем даже в Витрине** (слишком близко к реальному вреду или к реальному UX):

- поддельные системные диалоги ОС или браузера;
- реальные бренды;
- «зеркала» с реальными доменами — только `додеп-зеркало-47.нет` без ссылки;
- сбор каких-либо данных;
- кнопки, похожие на реальную оплату (картинки банковских карт, поля номера карты).
