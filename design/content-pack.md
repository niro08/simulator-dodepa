## 0. Как переносить в код

**Куда класть.** По CD-11 данные лежат в `src/game/content/*.ts`: только массивы и объекты с типами, без логики. Предлагаемая раскладка:

| Файл | Разделы этого документа |
|---|---|
| `endings.ts` | §1 |
| `events.ts` | §2 |
| `achievements.ts` | §3 |
| `ticker.ts` | §4 |
| `ads.ts` (баннеры, пуши, лобби) | §5 |
| `ui.ts` (кнопки, подписи, словарь Витрина→Изнанка) | §6, §7 |
| `statement.ts` (Выписка, счета, ломбард) | §8, §10 |
| `logs.ts` | §9 |
| `tilt.ts` | §11 |
| `onboarding.ts` (Как играть, подсказки, дисклеймер) | §12 |

**Ключи.** Везде `snake_case`, уникальные внутри раздела. Полный путь в коде строится как `раздел.ключ`, например `logs.shift.ok`.

**Варианты текста.** Если у ключа есть массив `variants`, код выбирает строку случайно, но не повторяет предыдущую.

**Плейсхолдеры** (подставляет код):

| Плейсхолдер | Что подставляется |
|---|---|
| `{amount}` | сумма операции |
| `{bet}` | ставка |
| `{win}` | выплата слота (брутто) |
| `{net}` | итог операции со знаком |
| `{loss}` | потеря (без знака) |
| `{mult}` | множитель |
| `{fee}` | комиссия |
| `{bonus}` | сумма бонуса |
| `{wager_left}` / `{wager_total}` | остаток / полный объём отыгрыша |
| `{expected}` | ожидаемый остаток после отыгрыша |
| `{item}` | вещь из ломбарда (с эмодзи) |
| `{day}`, `{week}`, `{days}` | день, неделя, число дней |
| `{bill}`, `{debt}`, `{interest}` | счёт, долг, проценты |
| `{wallet}`, `{casino_balance}` | кошелёк, баланс казино |
| `{tilt}`, `{rep}` | тильт, ❤️ |
| `{spins}`, `{rtp}`, `{ldw}`, `{near_miss}` | статистика слота |
| `{time}` | реальное время в игре |
| `{count}` | счётчик |
| `{title}` | титул игрока |
| `{help_link}` | ссылка на помощь (§12.4) |
| `{wager_done}` | сколько уже прокручено в счёт отыгрыша |
| `{ending_title}` | заголовок концовки |
| `{quit_count}` | сколько раз игрок завязал за всё время |
| `{timer}` | значение фейкового таймера |

Суммы форматирует код: пробел между тысячами, знак ₽ стоит сразу после числа (`{amount}₽`).

**Голоса** (CV §4):
- **V** (Витрина): КАПС, «бро», эмодзи, звёздочки-сноски.
- **I** (Изнанка): сухой протокол, моноширинный шрифт.
- **L** (Жизнь): бытовой, тёплый голос.

У каждого казино-элемента есть пара V/I (пиллар 1). Строка UI не длиннее 120 символов. Исключения: тела концовок и карточек событий.

**Обозначения эффектов:**

| Значок | Что меняется |
|---|---|
| 💵 | кошелёк |
| 🎰 | баланс казино |
| ⚡ | энергия (если не сказано иное, завтрашняя) |
| ❤️ | репутация |
| 🔥 | тильт |
| 💳 | долг |
| 📦 | вещь |

`balance_keys` — предлагаемые имена констант для `src/game/balance.ts`.

## 1. Концовки (7 + 3 оценки «Завязал»)

По CD-11 объём концовки — 60–120 слов, но владелец задал 2–4 предложения. Пишу по заданию владельца. У каждой концовки есть:
- `title` — заголовок;
- `text` — 2–4 предложения;
- `statement_line` — финальная строка Выписки;
- `locked_hint` — подсказка для силуэта «???» в Коллекции.

## 13. Открытые вопросы и отклонения

1. **Объём концовок.** По CD-11 нужно 60–120 слов, владелец задал 2–4 предложения. Писал по заданию владельца. Если нужно по CD-11, расширю.

3. **Новые механики в событиях.** Требуют решения CD-01/systems-designer:
   - `mama_blocks_site`: казино недоступно 1 день;
   - `boss_advance`: удержание из смен;

   - `dream_777`: ⚡ +10 сверх 100.

4. **Id ачивок.** `design/systems-spec.md` на момент написания ещё не было. Если id там другие, сопоставлять по полю `n` (номер в CV §8).
5. **Баннеры и словарь.** Сверх задания добавлены баннеры `happy_hour` и `mfo_partner` и словарь на 30 пар (по CD-11 нужно ≥ 25).
