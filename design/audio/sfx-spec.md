# SFX: спецификация (CD-20)

- **Автор:** Sound Designer · **Дата:** 2026-09-25 · **Источники:** CV §9 и пиллар 1, systems-spec §5.4, art-bible §3.13.
- **Код:** `src/audio/` (presets → packs → events → director → engine), фасад `src/composables/useSound.ts`, тесты `src/audio/audio.test.ts`.
- **Без файлов:** всё синтезируется на Web Audio (осцилляторы, белый шум, biquad-фильтры, огибающие). `public/audio/*.mp3` в SFX не используются. Старая фоновая музыка осталась под отдельным тумблером, по умолчанию она выключена (права на файл проверяет CD-39).

## Микс

| Параметр | Значение |
|---|---|
| Граф | голос → шина (master 0..1, кривая v², запас ×0.8) → лимитер (DynamicsCompressor: −10 dB, ratio 20, attack 2 мс) → выход |
| Голоса | не больше 10 одновременно, самый старый гасится за ~10 мс; вращение барабанов (старт, тики, стопы) — один голос |
| Пик ноты | ≤ 0.4 (тест) |
| Пачка событий | без дублей, ≤ 3 звуков по приоритету (ending > jackpot > casinoNight > bigWin/achievement > выигрыш…), шаг 120 мс |
| Дребезг | click 40 мс, reelTick/reelStop 20 мс |
| Изнанка («Снять очки») | исходы спина берутся из `honest`, весь звук ×0.55 |
| AudioContext | создаётся по первому pointerdown/keydown; без Web Audio (SSR, тесты) — noop |
| Громкость | `settings.sfxVolume` (ползунок в Настройках, M/🔊 — mute с возвратом к последней громкости) |

## Инварианты (тесты)

- Во всех паках, кроме honest: `ldw === win`, `push === win`, `lose === null`.
- honest: все исходы спина и депозит — `dry_click`, ачивка — `null`, на барабанах тишина.
- В Изнанке исходы спина — `dry_click` при любом паке.
- Паки = `COSMETICS.sounds`, у каждого слота существующий пресет или `null`.
- Тильт на исход и его звук не влияет (systems-spec §2.4).
