## 3. QA-09 v2: расширенный стоп-лист брендов

### 3.1 Что не так сейчас

`ru.test.ts` → `QA-09`: регэксп `telegram|телеграм|whatsapp|вконтакте|youtube|twitch|tiktok` по `TICKER_SHOWCASE` + `TICKER_HONEST`. Не видит: карточки сна, события, концовки, UI-строки, будущий чат, спонсоров и донаты; кириллические написания большинства брендов; казино, букмекеров, слоты, МФО, донат-сервисы.

### 3.2 Устройство

**Данные** — один модуль (TR §5 п.1 предлагает `src/i18n/stoplist.ts`), тест — один на все пулы. Три уровня:

| Уровень | Как матчит | Что при совпадении | Для чего |
|---|---|---|---|
| **A — жёсткий** | подстрока после нормализации | тест **падает** | уникальные токены, которых нет в обычном языке (`twitch`, `donationalerts`, `1xbet`, `азино`) |
| **B — по границе слова** | `(?<![\p{L}\p{N}_])токен(?![\p{L}\p{N}_])`, флаг `u` | тест **падает** | короткие токены, которые бывают частью слов (`kick` ≠ `kicker`, `сбер` ≠ `сбережения`, `втб`) |
| **C — ревью** | как B | тест **не падает**, печатает отчёт; падает, только если токен стоит в «ёлочках» или с заглавной буквы рядом со словами `казино / бет / слот / займ / энергетик / стрим` в одной строке | слова-омонимы: Вулкан, Олимп, Марафон, Киви, Авиатор, Стейк, Монстр |

**Важно для реализации:** `\b` в JS-регэкспах работает только с ASCII даже с флагом `u`. Для кириллицы `\bкик\b` не сработает как граница. Только lookaround с `\p{L}`.

**Нормализация перед сравнением:** NFKC → нижний регистр → `ё→е` → удалить U+00AD, U+200B–U+200D, U+2060, U+FEFF. Для уровня A дополнительно второй проход: (1) склейка латиницы без пробелов, точек и дефисов (`donation alerts`, `1 x bet`, `pin-up`), только для токенов ≥ 5 символов; (2) свёртка гомоглифов кириллица→латиница (`а→a, е→e, о→o, р→p, с→c, х→x, у→y, к→k, м→m, т→t, в→b, н→h`), чтобы поймать «Тwitch» со смешанной раскладкой.

**Что обходится:** рекурсивно все строковые значения экспортов `src/i18n/ru.ts`, `src/i18n/ui.ts` и пулов режима. Функции вызываются с фикстурами, как в нынешнем `ru.test.ts`. Ключи объектов не проверяются (`kicker` в `ui.ts:238` — имя поля). Новый пул регистрируется в одном реестре, иначе тест падает на «неизвестном экспорте» (TR §5 п.2).

**Allowlist** (по пути ключа, не по тексту):

## 7. Открытые вопросы и эскалации

1. **[UX, CD — блокирует AC-E4] Изнанка по кнопке против «пары в том же экране».** VIS §6 требует пару в том же экране, AC-E4 — чтобы ни один скриншот не читался как реклама. Но Изнанка переключается кнопкой 👓, и скриншот эфира без неё — чистая Витрина. Предложение: постоянный серый элемент цены в оверлее эфира, который не скрывается («Сегодня проиграно: N₽» или ❤️ рядом с 👁), плюс запрет на трейлер-клипы без Изнанки. Решение нужно до задачи 5.
2. **[game-designer] «Бодрячок»: `expired` или `failed`?** Противоречие §3.7.3 п.3 и §3.7.4 (AC-F6).
3. **[game-designer] Пары у строк Выписки** — всем строкам блока режима или только строке 1 (AC-F10)?
4. **[game-designer, TD] Событие `donationsPending`** нужно для тестируемости AC-F4. Добавить в список событий GDD-S и ADR.
5. **[writer] Переименовать** МФО «Быстроденьги-ну-почти» (BLOCK) и «Вован. Прогнозы» (REWRITE) до полного пула (задача 11). Привести тексты пилотных карточек СП1–СП3 к числам GDD-S или генерировать их из данных (QA-13).
6. **[producer] Юридическое ревью** рекламы азартных игр и займов (38-ФЗ, правила Steam) — вне компетенции QA. Нужен человек до релиза.
7. **[TD] Имена полей мета-флага:** GDD-S `streamerPrequelDone`/`streamerNick` против TR ADR-015 `profile.prequel`. AC сформулированы по поведению, но тесты задачи 9 нужно писать по принятому ADR.
8. **[qa-lead, до релиза] Поиск по §5** не выполнен из-за сетевого ограничения этой сессии. Повторить с доступом к сети или руками по списку источников §5.
